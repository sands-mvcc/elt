Understanding Transistor Operation & Characteristic Curves

NPN vs PNP:

  • • NPN: Current flows C→E when base is positive
  • • PNP: Current flows E→C when base is negative
  • • All voltage polarities reverse between types
  • • Characteristic curves have same shape

Input Characteristic:

  • • Exponential relationship between Ic and VBE
  • • Sharp turn-on around 0.7V (silicon)
  • • Small VBE changes cause large Ic changes
  • • Temperature sensitive

Transfer & Output:

  • • Transfer shows linear amplification (β)
  • • Output shows saturation behavior
  • • Three regions: cutoff, active, saturation
  • • β determines amplification factor
