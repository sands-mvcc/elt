Field Effect Transistors (FETs)

A Field Effect Transistor (FET) is a voltage-controlled semiconductor device where a small voltage at the Gate terminal controls a large current through the Drain-Source channel. Unlike bipolar transistors (BJTs) which are current-controlled, FETs have an extremely high input impedance — making them ideal for amplifiers, switches, and signal processing circuits.

⚡ FET vs BJT — Key Differences

  • BJT: Current-controlled device (IB controls IC)
  • FET: Voltage-controlled device (VGS controls ID)
  • FETs have much higher input impedance (MΩ to TΩ)
  • FETs are unipolar — only one carrier type (electrons OR holes)
  • FETs produce lower noise than BJTs
  • FETs are easier to fabricate in integrated circuits

🔧 FET Family Tree

  • JFET (Junction FET) — Gate is a reverse-biased p-n junction
  • MOSFET — Gate is insulated by a metal-oxide layer
  •   • Depletion-mode MOSFET — channel exists at VGS=0
  •   • Enhancement-mode MOSFET — channel formed by VGS
  • N-channel: electrons are majority carriers (most common)
  • P-channel: holes are majority carriers (complementary circuits)
Three FET Terminals

Source (S)

The terminal from which majority carriers enter the channel. Acts like the emitter in a BJT. Always connected to the most negative voltage in an N-channel device. The channel current ID flows into the drain and out of the source.

Drain (D)

The terminal where majority carriers exit the channel. Connected to the supply voltage VDD through a drain resistor RD. The drain current ID is controlled by VGS. Acts like the collector in a BJT.

Gate (G)

The control terminal. A voltage VGS applied here controls channel width and therefore ID. In a JFET, the gate is a reverse-biased p-n junction. Gate draws essentially zero current — giving FETs their high input impedance.

Key JFET Parameters Students Must Master

IDSS

Drain-to-Source Saturation Current. Maximum drain current when VGS = 0V. Typical values: 1–20 mA. All JFET operation occurs between 0 and IDSS.

VP (Pinch-off)

Pinch-off Voltage. The VGS value at which the channel is fully depleted and ID → 0. Negative for N-channel JFETs. Also equals the VDS where saturation begins at VGS=0.

gm

Transconductance. Ratio ΔID/ΔVGS. Measured in Siemens (S) or mA/V. Key amplifier parameter: higher gm = higher voltage gain. Maximum at VGS=0.

rDS(on)

On-state Drain-Source Resistance. Resistance when device is fully ON (ohmic region). Critical for switching applications — lower rDS(on) means less power loss.

Ohmic Region (Linear)

When VDS is small relative to VP, the channel acts as a voltage-controlled resistor. ID rises nearly linearly with VDS. The FET operates here as a variable resistor or analog switch.

Saturation (Pinch-off) Region

When VDS ≥ VGS − VP, the channel pinches off at the drain. ID becomes nearly constant and independent of VDS. This is the normal amplifier operating region.

Breakdown Region

When VDS exceeds the avalanche breakdown voltage (BVDSS), ID increases rapidly. This region is destructive if sustained. Must always operate below BVDSS.

⚡ How Depletion Works (N-Channel)

  • The gate is P-type material alongside the N-type channel
  • Gate is reverse-biased: VGS is negative for N-channel
  • More negative VGS → wider depletion region → narrower channel
  • At VGS = VP (pinch-off): channel fully depleted, ID = 0
  • At VGS = 0: channel fully open, ID = IDSS
  • Gate current IG ≈ 0 (reverse-biased junction)

🔬 Shockley's Equation

The drain current in the saturation region is described by:


ID = IDSS (1 − VGS/VP)²


  • Parabolic relationship between ID and VGS
  • At VGS = 0: ID = IDSS
  • At VGS = VP: ID = 0
  • Non-linear — unlike BJT's linear IC vs IB

Knee / Pinch-off Line

The boundary between ohmic and saturation regions occurs at:


VDS(sat) = VGS − VP


Above this line the device enters saturation. For amplifier design, the Q-point must lie in the saturation region.

Transconductance gm

gm = gm0(1 − VGS/VP)

  • gm0 = 2IDSS/|VP| (max at VGS=0)
  • gm decreases as VGS goes more negative
  • Slope of tangent to parabola at Q-point
  • Controls amplifier voltage gain: Av = −gmRD

Shockley's Equation

ID = IDSS(1 − VGS/VP)²

  • Parabolic (square-law) characteristic
  • Valid for saturation region only
  • Two key endpoints: (0, IDSS) and (VP, 0)
  • Midpoint VGS: ID = IDSS/4

Self-Bias Analysis

  • VGS = −ID × RS (self-bias equation)
  • No separate VGG supply needed — RS provides bias
  • VG = 0 (RG connects gate to ground, IG ≈ 0)
  • VS = ID × RS (source voltage)
  • VD = VDD − ID × RD
  • VDS = VD − VS = VDD − ID(RD+RS)

Q-Point Design Tips

  • For maximum output swing: set ID(Q) ≈ IDSS/2
  • Increase RS → more negative VGS → lower ID
  • Decrease RS → less negative VGS → higher ID
  • RG is large (1MΩ+) to ensure high input impedance
  • Saturation condition: VDS > VGS − VP
  • Temperature stability: RS provides negative feedback

Common-Source Amplifier

  • Voltage gain: Av = −gmRD
  • Phase: 180° inversion (like BJT common-emitter)
  • Input impedance: Zin = RG (very high)
  • Output impedance: Zout ≈ RD
  • Bypass capacitor on RS increases gain

Other JFET Configurations

  • Common-Gate: No phase inversion, low Zin, high Zout
  • Common-Drain (Source Follower): Vout follows Vin, Av≈1, very high Zin
  • Source follower used as buffer between high-Z source and low-Z load
  • JFETs excel in RF amplifiers due to low noise

✅ Design Checklist

  • V_GS between V_P and 0 for N-ch JFET?
  • V_DS > V_DS(sat) for saturation?
  • I_D < I_DSS at all times?
  • V_DD sufficient for desired V_DS(Q)?
  • R_G large enough for high Z_in?
  • Power dissipation P = V_DS × I_D < P_max?

⚡ Common JFET Types

  • 2N5457: N-ch, I_DSS 1–5 mA, V_P −0.5 to −6V
  • 2N5459: N-ch, I_DSS 4–16 mA, audio amp
  • J201: N-ch, low I_DSS, guitar effects
  • MPF102: N-ch, RF/VHF amplifier
  • 2N5460: P-ch, complementary circuits
  • BF245: N-ch, low noise, HF amp

🔄 JFET Applications

  • Low-noise RF & audio amplifiers
  • Voltage-controlled resistors (ohmic region)
  • Analog switches and multiplexers
  • Sample-and-hold circuits
  • Constant-current sources
  • Electrometer/instrumentation inputs
